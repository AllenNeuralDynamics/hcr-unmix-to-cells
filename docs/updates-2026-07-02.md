# Cell-typing capsule updates — 2026-07-02

Summary of changes made to the `hcr-unmix-to-cells` (cell-typing) capsule and its
launcher on 2026-07-02.

## 1. Consolidated cell typing table

**New:** `code/cell_typing_table.py`, wired into `code/run_capsule.py`.

After the strategy branches run, the capsule now writes one root-level table of
every HCR cell with its assignment(s) to `results/cell_typing_table.csv`:

- **Both methods ran** → the TASIC and MapMyCells per-method tables are merged
  (outer join) on the cell id.
- **Only one ran** → a cleaned copy of that method's table.

Source tables:

| Method | Source file |
|--------|-------------|
| TASIC | `results/tasic_superclusters/stage5/hcr_assignments_leiden_named.csv` |
| MapMyCells | `results/mapmycells/inhibitory_cells_{spots}/mapped_data/basic_results.csv` |

Per-method column handling:

- **TASIC** — drop `leiden_cluster`; rename `branch`→`leiden_subclass`,
  `assignment`→`leiden_assignment`, `confidence`→`leiden_confidence`; keep
  `cell_id` and `mouse_id`.
- **MapMyCells** — drop the label/consistency columns (`hierarchy_consistent`,
  `class_label`, `subclass_label`, `supertype_label`, `cluster_label`); keep
  `cell_id` as the join key; prefix every other column with `mapmycells_`.

Cell-id alignment: TASIC ids are `{mouse_id}_{cell}` (e.g. `790322_6868`) while
MapMyCells ids are the bare cell number (e.g. `6868`). The `{mouse_id}_` prefix
is stripped from the TASIC ids so both tables merge on the same key, and
`mouse_id` is kept as its own column (back-filled for MapMyCells-only rows from
the run's `mouse_id`).

Final column order: `cell_id, mouse_id, leiden_*, mapmycells_*`.

## 2. `--spots` (filtered / all_spots) now applies to TASIC too

Previously the `--spots` flag (`filtered` default, or `all_spots` unfiltered)
only selected the HCR spot subset for MapMyCells; TASIC was hardwired to the
**filtered** inhibitory table.

`--spots` now drives both strategies. `all_spots` is threaded through
`run_tasic_superclusters.main → run_stage1 → load_hcr_multi_mouse →
load_inhibitory_cells(all_spots=...)` and recorded in the TASIC
`run_params.json`. TASIC remains inhibitory-only; only the filtered/all_spots
axis is selectable. MapMyCells behavior is unchanged (it still maps both the
inhibitory and all-cells tables for the chosen subset).

**Note:** the `--spots` parameter was **not** added to the Code Ocean app panel
(`.codeocean/app-panel.json`). It works via the CLI / named parameters; add the
dropdown through the Code Ocean app-builder GUI when it should be visible there.

## 3. Bug fix: MapMyCells `basic_results.csv` parsing

`cell_type_mapper` prefixes `basic_results.csv` with `#`-commented metadata lines
(taxonomy hierarchy, algorithm, version) that contain commas. This made
`pd.read_csv` raise a tokenizing `ParserError` when building the cell typing
table. The MapMyCells CSV is now read with `comment="#"` so those lines are
skipped. (The TASIC table has no such header and is read as-is.)
